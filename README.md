# Aeacus — VAE-based Fraud Detection

Course project, **Unsupervised Learning (TAU, 2023)**. Not maintained.

Uses a Variational Autoencoder on the [Credit Card Fraud dataset](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) and compares three approaches: AE + Deep SVDD, classifier on VAE latents, and SMOTE in latent space. Evaluated with PR-AUC.

PyTorch, scikit-learn, imbalanced-learn.
